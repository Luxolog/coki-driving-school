# Coki K53 — Imported Inganathi Study Reference

This folder is a preserved copy of the study material from the separate `Luxolog/inganathi-k53` project, added as a reference library for Coki.

## Files
- `manual.html` — complete K53 study manual (Rules of the Road, Road Signs, Vehicle Controls, study guidance and embedded section practice).
- `pertinent-knowledge.html` — supplementary pertinent-knowledge notes.
- `questions-and-answers.html` — question-and-answer reference.
- `clean_questions.json` — structured question bank.
- `road_signs.json` — structured road-sign and road-marking catalogue.

## View the imported material
Open [manual.html](./manual.html), [Pertinent Knowledge](./pertinent-knowledge.html), or [Questions & Answers](./questions-and-answers.html).

## Source and asset handling
Source repository: https://github.com/Luxolog/inganathi-k53  
Original published manual: https://luxolog.github.io/inganathi-k53/manual.html

The imported HTML and JSON are kept in this separate folder so existing Coki application files and functionality are not overwritten. Image references point to the original published Inganathi asset URLs so the diagrams and sign artwork continue to load without duplicating binary assets in this import. This means those images still depend on the original Inganathi site remaining available.

This is a source-material import only. It does not change Coki's homepage, branding, learner portal, tests, admin preview, or application configuration. The imported study content should be reviewed for accuracy and Coki-specific presentation before being integrated into the learner experience.
