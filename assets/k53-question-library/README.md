# Coki K53 Question Image Library

Upload the original K53 question illustrations and sign images to this folder.

## Purpose

This is a central image library for building additional Coki K53 practice tests. When new question sheets and images are supplied, compare each question's visual with this library to identify an existing matching image before adding a duplicate.

## Upload instructions

- Upload the original image files here; keep the original image unchanged.
- Use descriptive filenames where possible, for example `road-sign-001.jpg`, `diagram-heavy-vehicle-002.png`, or retain the source filename.
- If an image belongs to a particular question sheet, include that source/set name in the filename or upload it in a named subfolder.
- Supported common formats: PNG, JPG/JPEG, WEBP and SVG.
- Do not combine several different signs into one image if they can be uploaded separately.
- Do not add answer keys, learner personal information, or unrelated documents to this folder.

## Matching workflow

For every new question set:

1. Read the question wording and identify its referenced sign, diagram or road scene.
2. Compare the supplied illustration with images already in this library.
3. Reuse an existing image when the visual is the same; record the matched file path.
4. If no reliable match exists, add the supplied original image to this library and link the question to it.
5. Keep question wording, options and answer keys in the relevant test data files. This folder is for reusable image assets only.

## Important image rules

- Match by the actual visual, not filename alone.
- Do not redraw, AI-generate, recolour, crop, or otherwise modify source illustrations unless explicitly requested.
- Preserve red elements that are part of an original road sign. Remove answer markings or annotation arrows only when they are clearly separate overlays and the clean original is available or the user has asked for that edit.
- Never guess a match when the illustration is unclear; flag it for confirmation.

## Suggested naming pattern

`<source-set>-<sequence>-<short-description>.<extension>`

Example: `k53-set-02-014-stop-sign.jpg`
