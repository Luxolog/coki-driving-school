Learner assessment

Five-test practice centre

Choose from five 64-question practice tests. Enter your Coki student ID before starting. Every attempt shuffles the questions and answer choices, and a retake moves questions away from their previous question numbers. After finishing, review every incorrect answer and its correct answer. Road-sign and vehicle-control diagrams appear where provided by the source.

Practice format: Each test contains 64 questions drawn from the imported 236-question source bank. Questions may appear in more than one test, but do not repeat within the same test attempt. Retake orders are changed so a question does not keep its previous number. Results are currently saved in the same browser with the student ID; connection to the secure admin dashboard will follow when the learner database is ready.
